# Widget Icons

Place your custom icons in this folder with the following names:

- `auth-icon.png` - Authentication widget icon (replace 🔐)
- `branding-icon.png` - Branding widget icon (replace 🎨)
- `theme-icon.png` - Appearance/Theme widget icon (replace 🌓)
- `azure-icon.png` - Azure Configuration widget icon (replace ☁️)
- `data-icon.png` - Data Management widget icon (replace 🗑️)

All icons should be square (e.g., 40x40px or 80x80px) and in PNG format with transparency.

User-uploaded logos will be saved here as well.
